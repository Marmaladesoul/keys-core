# What every query of every run must print, for run.sh.
#
# One line per ProVerif run: a model (pairing/<model>.pv), the transport
# library and the binding library it is loaded with, extra options, then the
# result expected of each query in file order: `true`, or `false` for a
# query that is meant to fail (a sanity check or an attack witness).
# `unproved` is what run.sh calls a query ProVerif can't decide; nothing
# here expects it.
#
# options: `-` for none; `precise` sets preciseActions, which ProVerif needs
# to rebuild the attack traces of those runs.
#
# binding: `current` is the protocol; `noshares` is the weakened key-set
# signature of binding-noshares.pvl, which only the misbinding models are
# run with.
#
# run.sh refuses a manifest that leaves out a model in pairing/ under either
# transport with the `current` binding, repeats a run, or lists a run with
# no expected results.
#
# Heaviest models first, so the job pool packs well.
